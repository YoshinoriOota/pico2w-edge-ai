# 『Raspberry Pi Pico 2 WとOV7670で作る 電池で動くエッジAIカメラ』（目次）

**想定環境**: Sony Neural Network Console 3.50（Windows・GUI）/ Raspberry Pi Pico 2 W（RP2350）+ OV7670 / MicroPython（dnnrt 組み込みファームウェア）
**想定読者**: Python の初歩がわかり、電子工作に興味がある初中級者。AI・電子回路の予備知識は不要

**アーキテクチャ（3ステージ）**:
NNC（GUI で学習）→ NNC から .nnb を直接エクスポート → Pico 2 W（MicroPython + DNNRT で推論、電池駆動・間欠動作）

**本書の売り**: 読者が書くコードはすべて Python。学習は GUI で完結、C 言語は一切不要。「電池で動く」を実測データ付きで示す
